# Признаки стресса (без камеры — только гипотезы)

> Требуют подтверждения FACT-данными. Без датчиков — confidence LOW.

| Признак | Возможные связи с датчиками |
|---------|----------------------------|
| Вянутые листья | soil low, temp high, root issue |
| Жёлтые нижние листья | overwater, N deficiency, natural senescence |
| Вытягивание | low DLI / short photoperiod |
| Tip burn | low RH / high VPD |
| Плесень | RH high + poor airflow |

Agent формулирует: «по показаниям X возможно Y» — не диагноз.
