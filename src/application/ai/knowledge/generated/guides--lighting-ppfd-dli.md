# Освещение: PPFD, DLI, фотопериод

## Базовые определения

- **PPFD** (µmol/m²/s) — поток фотонов на canopy.
- **DLI** (mol/m²/day) = PPFD × seconds_of_light / 1e6.
- **Photoperiod** — часы света/темноты (18/6, 12/12).

Пример: PPFD 400 × 18 h × 3600 s ≈ 25.9 mol/m²/day DLI.

## Ориентиры DLI (indoor, PROJECT_DECISION ranges)

| Культура / фаза | DLI mol/m²/day |
|-----------------|----------------|
| Рассада / микрозелень | 10–15 |
| Листовые (салат, базилик) | 12–17 |
| Томат/огурец вега | 20–30 |
| Цветение/плоды (высокий свет) | 25–35+ |

## Для QBX

- Без PPFD/light sensor — **не утверждай** DLI; только photoperiodHint из GrowPhase.
- Рассвет/закат (ramp) снижают стресс — automation playbook.
- CO₂ имеет смысл при **активном** свете (см. co2-enrichment).

## Типичные проблемы

| Симптом | Возможная причина |
|---------|-------------------|
| Вытянутые стебли | Низкий DLI |
| Ожог верхушки | PPFD слишком высокий / близко |
| Медленный рост при «длинном дне» | Низкий PPFD, не часы |
