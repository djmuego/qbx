# IPM и патология (базово)

## Принцип QBX

- **Не** ставить диагноз «болезнь X» без подтверждения.
- Формат: вероятные причины + confidence + «что проверить».

## Частые проблемы vs микроклимат

| Наблюдение | Проверить сначала (FACT) | Возможное INFERENCE |
|------------|--------------------------|---------------------|
| Пятна на листьях | RH, leaf wetness, airflow | Грибок при высокой RH |
| Мелкая сеть | RH, temp | Клещ при сухом жарком |
| Жёлтые нижние листья | EC, pH, soil trend | N-deficiency или overwater |
| Вянут днём | soil, VPD, temp | Жажда vs корни |

## Профилактика (RECOMMENDATION)

- Вентиляция + VPD в цели → меньше грибка.
- Quarantine новых растений.
- Липкие ловушки / осмотр 2×/нед (user action).

## Vision (будущий Pass)

Фото → CV hints → те же правила evidence; не auto pesticide commands.
