# Субстраты и гидропоника

| Субстрат | Полив | Датчики | Заметки |
|----------|-------|---------|---------|
| Почва | Умеренно реже | Soil moisture | Буфер влаги, pH почвы |
| Кокос | Частые циклы dryback | Soil/WC, EC drain | Солёность критична |
| Минвата | Точный полив | WC, drain % | Мало прощает перелив |
| NFT/DWC | Непрерывный/цикличный | EC, pH, temp solution | Корневая зона O₂ |
| Aeroponics | Короткие mist cycles | EC, pH, pressure | Чувствителен к сбоям |

## Root-zone temperature

- Оптимум для многих культур: **18–22°C** (PROJECT_DECISION).
- Холодная корневая зона → медленный uptake, риск Pythium в сырости.

## Для Agent

- `medium` из CropProfile → подсказать типичный режим полива.
- Без drain/WC sensor — не утверждай «dryback 12%».
