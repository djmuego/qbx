# Микроклимат: базовые ориентиры

> Цифры — ориентиры для домашней теплицы / гроубокса. Точные цели задаёт **фаза роста** в QBX и конкретная культура.

## Температура воздуха

| Зона | Комфорт для большинства овощей |
|------|--------------------------------|
| День | 22–28 °C (зависит от культуры) |
| Ночь | На 2–4 °C ниже дня — нормально |
| Риск | >32 °C — стресс, опыление может страдать; <12 °C — замедление роста |

**Ночной перегрев** (мало падения температуры) → вытягивание, слабые цветки.

## Влажность воздуха (RH)

| Фаза | Типичный диапазон |
|------|-------------------|
| Проращивание / рассада | 65–75 % |
| Вегетация | 55–65 % |
| Цветение / плодоношение | 40–55 % |

Высокая RH + плохая вентиляция → плесень, гниль. Низкая RH → стресс, ожоги кончиков листьев.

## Световой цикл

| Режим | Когда |
|-------|-------|
| 18/6 | Рассада, вегетация |
| 12/12 | Цветение (фотопериодные культуры) |

Недостаток DLI (суммарного света за день) → слабые растения даже при «правильной» температуре.

## VPD (упрощённо)

VPD — «насколько сухой воздух для испарения с листа». Слишком низкий VPD → растение «не тянет» воду, риск грибка. Слишком высокий → закрытие устьиц, стресс.

Грубая связка: при **22–26 °C** комфортный RH часто **50–65 %** на вегетации.

## Что делать Agent при отклонении

1. Сравнить snapshot с целями фазы (`growPhaseTargets` в QBX).
2. Если есть live-данные — указать конкретное отклонение.
3. Предложить **действие в QBX**: вентиляция, увлажнитель, полив, свет — через автоматизации или ручной режим.
