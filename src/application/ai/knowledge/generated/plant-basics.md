# Основы: что нужно растению

## Четыре опоры роста

1. **Свет** — энергия для фотосинтеза. Без достаточного света растение вытягивается, листья бледнеют.
2. **Вода** — транспорт питательных веществ, turgor (упругость тканей). Недостаток → вянут листья; избыток → гниль корней.
3. **Воздух (CO₂ + обмен)** — листья «дышат». Застой влажного воздуха повышает риск плесени.
4. **Субстрат / питание** — NPK и микроэлементы. На ранних стадиях важнее баланс влаги и света, чем «максимум удобрений».

## Части растения (кратко)

| Часть | Роль |
|-------|------|
| Корни | Вода, минералы, закрепление. Чувствительны к переувлажнению и холоду |
| Стебель | Транспорт, опора |
| Листья | Фотосинтез, испарение (транспирация) |
| Соцветия / плоды | Репродукция; требуют больше света и часто ниже влажности |

## Типичные симптомы (общие, не диагноз)

| Симптом | Возможные причины (проверять по датчикам!) |
|---------|---------------------------------------------|
| Вянутые листья днём | Недолив, перегрев, повреждение корней |
| Жёлтые нижние листья | Естественное старение **или** переувлажнение / дефicit азота |
| Вытягивание | Мало света |
| Капли на кончиках листьев (guttation) | Высокая влажность + активный корень, часто ночью — обычно не критично |
| Плесень на листьях | Высокая RH, плохой обмен воздуха |

## Принцип для QBX

Сначала смотри **live-данные** (температура, RH, влажность почвы). Базовые знания помогают объяснить, *почему* отклонение важно и *что* проверить в автоматизациях.
