# CO₂ enrichment

## Когда имеет смысл

- **Свет активен** (фотосинтез идёт).
- **Вентиляция не вытягивает** весь CO₂ (закрытая CEA).
- Типичные цели indoor: **800–1200 ppm** при хорошем свете (PROJECT_DECISION — зависит от культуры).

## Когда НЕ имеет смысл

- Свет выключен → не рекомендовать подачу CO₂.
- Сильная вытяжка ON → CO₂ уходит, трата бессмысленна.
- Нет CO₂ sensor → только общие советы, не «сейчас 400 ppm».

## Связь с климатом

- CO₂ + свет + temp + VPD — единая модель (climate-coupling).
- Высокий RH + CO₂ без вентиляции → риск плесени на листьях.

## Для Agent

- missingData: «Нет CO₂ sensor» если нет live CO₂.
- Не утверждай ppm без FACT-датчика.


## Для QBX

FACT (runtime) > markdown. При отсутствии sensor — честно про UNKNOWN.
