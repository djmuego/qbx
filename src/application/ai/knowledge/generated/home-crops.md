# Домашние культуры: базовые профили

> Справочник для советов Agent. Текущая **фаза в QBX** и **live-датчики** важнее этих таблиц.

## Культуры (ориентиры)

## Томат (тёпличный / гроубокс)

| Параметр | Вегетация | Цветение / плод |
|----------|-----------|-----------------|
| Температура | 24–26 °C день | 22–24 °C, ночь не ниже ~16 °C |
| RH | 55–65 % | 45–55 % |
| Свет | 18/6, много DLI | 12/12 или 18/6 (зависит от сорта) |
| Почва | 50–60 % | 45–55 % |

Заметки: резкие скачки RH мешают опылению; при >28 °C — усилить вентиляцию.

## Огурец

| Параметр | Ориентир |
|----------|----------|
| Температура | 24–28 °C день, не ниже 18 °C ночь |
| RH | 60–70 % (любит влажнее томата) |
| Почва | 60–75 %, не допускать длительной сухости |

## Перец (сладкий / острый)

| Параметр | Ориентир |
|----------|----------|
| Температура | 24–27 °C день; <15 °C — стресс |
| RH | 50–60 % |
| Почва | 45–60 % |

## Салат / зелень (листовые)

| Параметр | Ориентир |
|----------|----------|
| Температура | 18–22 °C (перегрев → горькость, стрелка) |
| RH | 50–65 % |
| Свет | 14–16 ч, умеренная интенсивность |
| Почва | 55–70 % |

## Базилик / зелень пряная

| Параметр | Ориентир |
|----------|----------|
| Температура | 22–26 °C |
| RH | 50–60 % |
| Почва | 45–55 %, не заливать |

## Как Agent использует профиль

1. Если пользователь назвал культуру в описании пространства — опираться на профиль.
2. Сравнивать **только при наличии** live temperature / RH / soil в snapshot.
3. Рекомендовать настройку **автоматизаций QBX**, а не «полей вручную каждый час».


## Для QBX

FACT (runtime) > markdown. При отсутствии sensor — честно про UNKNOWN.
